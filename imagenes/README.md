# Recursos visuales de EcoRuta

- `mercado-ecoruta.webp`: imagen panorámica para la portada y secciones de acceso/administración.
- `separacion-residuos.webp`: imagen ilustrativa para la explicación de separación de residuos y los reportes.

Ambas imágenes fueron generadas para este prototipo y convertidas a WebP para reducir su peso de descarga. Son ilustrativas, no fotografías documentales que certifiquen una escena real del mercado.
